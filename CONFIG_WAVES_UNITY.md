## 🔧 Passos para Configurar no Unity

### 1. Abrir WaveManager
1. Na **Hierarchy**, localize o GameObject com o componente **WaveManager**
2. Selecione-o para ver no **Inspector**

### 2. Configurar Array de Waves
1. No Inspector, localize **Waves Configuration**
2. Defina **Size**: `20`
3. Isso criará 20 elementos vazios

### 3. Configurar Cada Wave
Para cada elemento (Wave 0 a Wave 19):

#### Passo 1: Nome da Wave
- Digite o nome: "Wave 1", "Wave 2", etc.

#### Passo 2: Enemy Normal
- **Enemy Normal Prefab**: Arraste o prefab do inimigo normal
- **Enemy Normal Count**: Digite o número da tabela
- **Enemy Normal Spawn Delay**: Digite o delay da tabela

#### Passo 3: Enemy Tank (Waves 5-20)
- **Enemy Tank Prefab**: Arraste o prefab do tank (ou None para Waves 1-4)
- **Enemy Tank Count**: Digite o número da tabela (ou 0)
- **Enemy Tank Spawn Delay**: Digite o delay (se aplicável)

#### Passo 4: Enemy Voador (Waves 10-20)
- **Enemy Voador Prefab**: Arraste o prefab do voador (ou None para Waves 1-9)
- **Enemy Voador Count**: Digite o número da tabela (ou 0)
- **Enemy Voador Spawn Delay**: Digite o delay (se aplicável)

### 4. Verificar Spawn Point
- Certifique-se de que o campo **Spawn Point** está configurado
- Arraste o Transform de onde os inimigos devem spawnar

### 5. Configurações Adicionais
- **Auto Start**: True (para começar automaticamente)
- **Delay Before First Wave**: 3.0 (segundos antes da primeira wave)

---

## ⚡ Dicas de Configuração

### Atalhos no Unity:
1. **Copiar valores**: Clique direito no componente → Copy Component
2. **Colar valores**: Clique direito no próximo → Paste Component Values
3. **Lock Inspector**: Clique no cadeado para manter Inspector aberto

### Organização:
1. Configure Waves 1-4 primeiro (só Normal)
2. Configure Waves 5-9 depois (Normal + Tank)
3. Configure Waves 10-20 por último (Normal + Tank + Voador)

### Teste Progressivo:
1. Configure apenas Waves 1-5 primeiro
2. Teste no Play Mode
3. Ajuste se necessário
4. Continue configurando o restante

Após configurar todas as 20 waves:

### Checklist de Teste:
- [ ] Wave 1 spawna 5 inimigos normais
- [ ] Wave 5 spawna tanks pela primeira vez
- [ ] Wave 10 spawna voadores pela primeira vez
- [ ] Wave 20 é intensa e desafiadora
- [ ] Timer de 30s funciona entre waves
- [ ] Popups aparecem corretamente
- [ ] Dinheiro é distribuído após kills
- [ ] Vitória é declarada após Wave 20

### Se algo não funcionar:
1. Verifique se os prefabs estão corretos
2. Verifique se o Spawn Point está configurado
3. Verifique se ResourceManager está na cena
4. Verifique se WaveTimerUI está na cena
5. Verifique Console para erros

## 📋 Copiar para Outros Mapas

Depois de configurar no primeiro mapa (ex: map_div):

1. Selecione o GameObject **WaveManager**
2. Clique direito no componente **Wave Manager** → **Copy Component**
3. Abra a cena **map_first**
4. Selecione o GameObject **WaveManager**
5. Clique direito no componente → **Paste Component Values**
6. **IMPORTANTE**: Verifique se o **Spawn Point** está correto para esta cena
7. Repita para **map_split**

**Pronto! As mesmas 20 waves estarão em todos os 3 mapas!** 🎯
